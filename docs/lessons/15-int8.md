# 15 — Groupwise symmetric INT8 weights

`GroupwiseInt8` represents one weight matrix W[O,I]. Signed byte values are
row-major. Scales are [O,ceil(I/G)] row-major; groups never cross an output row.
The teaching default is G=32, with explicit sizes1..256 available for tests.
Norms and biases remain FP32: this ticket does not quantize the decoder or select
a production precision. No file format, model download or dependency is added.

For each group, find max absolute weight M. Scale s=M/127 in FP32, except an
all-zero group uses s=1 and q=0. Encode q=round(w/s), with an FP32 quotient,
nearest ties away from zero, then clamp to[-127,127]. Reconstruct w'=q*s in
FP32. The unused -128 code makes positive/negative ranges symmetric. Tail groups
use only their actual remaining weights. Nonfinite weights, overflowing dimension/
payload arithmetic, inexact lengths and invalid groups are rejected. A nonzero
scale that underflows to zero or a reconstruction that overflows is rejected;
no hidden precision switch or guessed scale is used.

The constructor validates shapes/payload and all finite weights before allocation,
then uses fallible reserved storage. Private fields prevent unvalidated q/scales
from reaching execution. `dequantize` writes a caller-owned full matrix for the
reference; exact output length is checked before writes. `linear_int8` validates
input/output shapes, then reads one encoded group and its scale into the scalar
dot. Each weight is reconstructed in a register, multiplied by its activation,
and added in increasing input-index order. It never builds a full FP32 matrix
per token. Activations/accumulation remain FP32. Numerical NaN/overflow behavior
is ordinary arithmetic; a model caller must validate results before cache commit.

Near halves, the specified FP32 quotient matters. Fixed input/scale bits give a
FP64 ratio63.4999987599 but an FP32 quotient63.5, so q=64. The initial oracle used
only the FP64 ratio and expected63. The corrected independent equation rounds
the quotient once to FP32 before applying nearest-away-from-zero; a fixed-bit
regression now records the boundary. Production arithmetic and tolerance did not
change. Rounding/clamping constants, zero groups, tails and reconstructed error
are tested separately. Independent FP64 output equations retain the operator
gate atol1e-5/rtol1e-4. For tested normal scales, reconstruction error is bounded by s/2 plus
4*FP32 epsilon*M for division/reconstruction rounding; this is not a full-model
quality gate. Positive subnormal scales are admitted, and their coarse rounding
can activate clamping even at the group maximum. For weight bits190, scale bits1
and q127 reconstruct bits127: error63 minimum-subnormal units. The normal-scale
bound does not apply. This boundary is explicitly tested; scales that round to
zero remain rejected.

**Trace:** W has two width5 rows: `[127,.5,-.5,0,254]` and all zeros, G=4.
Scales are `[1,2,1,1]`; encoded rows are `[127,1,-1,0,127]` and zeros. The last
weight is reconstructed with its tail scale2. For X=`[.5,2,-1,4,.25]`, the first
dot is `63.5+2+1+0+63.5=130`; second is0. The unquantized first dot is128.5,
illustrating quantization error even though fused/reference quantized execution
agree exactly. Encoded payload26bytes versus40FP32 includes scales; this tiny
tail-heavy shape saves less than a large G32-aligned matrix.

Payload bytes exclude allocator/metadata overhead and are not file size or RSS.
No inference speedup or complete model quality is established here. T16 must
freeze a quality floor before choosing a representation and compare actual
teacher-forced logits/loss, memory and prefill/decode. Keep the FP32 path.
